Football Play-by-Play Parser App
================================

How to open the app
-------------------

1. Open the FootballParserApp folder.

2. Double-click:

   FootballParserApp.exe

3. A browser window should open automatically.

4. If the browser does not open automatically, open your browser and go to:

   http://127.0.0.1:5000


Important
---------

Do not move FootballParserApp.exe out of this folder.

The app needs the surrounding folders to work correctly.


Where files are saved
---------------------

Downloaded PDFs are saved in:

   data/temp

Excel exports are saved in:

   data/exports


If Windows blocks the app
-------------------------

Windows may show a warning because this is a custom app.

Click:

   More info

Then click:

   Run anyway


If parsing does not work
------------------------

Make sure the folder contains a file named:

   .env

That file should contain the API key needed by the parser.
